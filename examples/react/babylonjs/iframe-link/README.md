# Embedding bitbybit.dev previews in your site

A page that embeds two bitbybit.dev script previews as iframes and links to the scripts. No
bitbybit packages are involved: the previews run on bitbybit.dev, and this shows how a website
includes them.

## Running it

```
npm install
npm run dev        # http://localhost:3000
npm run build      # production bundle in dist/
npm run preview    # serve the production bundle
```

The app is a [Vite](https://vite.dev) + React project.
