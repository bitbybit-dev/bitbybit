# Rendering 3D Objects in Bitbybit Editors

<img 
  class="category-icon-small" 
  src="https://s.bitbybit.dev/assets/icons/white/draw-icon.svg" 
  alt="Draw category icon with a paintbrush" 
  title="Draw category icon" /> 

This guide demonstrates how to use the core "Draw" functionalities across Bitbybit's different editor environments: Rete, Blockly, and TypeScript. The objective is to render a 3D object-specifically, a cube with rounded edges-and customize its appearance.

## A filleted cube with its own colours

The script builds a cube, rounds its edges with a fillet, and draws the result with options of its own: blue faces, light red edges, and its vertices drawn as points.

Each editor draws it the same way:

- **Rete:** the **draw any async** component, in the palette's `draw` category under its `draw async` heading.
- **Blockly:** the **draw any async no return** block, in the toolbox under `draw` > `draw async`. The blocks are nested directly, without variables in between.
- **TypeScript:** `bitbybit.draw.drawAnyAsync`, with a `Bit.Inputs.Draw.DrawOcctShapeOptions` for the options.
