# Technical drawings from a model

A technical drawing shows a part from one direction as lines: the edges the eye sees, and often the edges hidden behind faces, drawn thinner or dashed. `bitbybit.occt.operations.hiddenLines` makes that drawing from any shape and any view, flat on the ground plane, ready to draw in the scene or to export as SVG or DXF.

## The view

The view is a frame (see [Frames](/learn/code/common/base/frame/intro)). The eye sits on the side the frame's normal points to and looks back along it, and the drawing's x runs along the frame's direction. A normal of `[0, 0, 1]` gives a front view, `[0, 1, 0]` a plan from above, `[1, 1, 1]` the corner view of the example. The drawing is centered on the frame's origin, so put the origin at the part's middle.

`hiddenLines` returns two compounds of edges: `visible` and `hidden`. Its options:

- `hiddenEdges` (true) collects the hidden edges; with false, `hidden` stays empty.
- `smoothEdges` (false) also draws the edges where faces meet without a crease, such as the borders of a fillet.
- `focus` (0) gives a perspective view from that distance; 0 is a parallel view, as technical drawings use.
- `exact` (true) works from the exact geometry; false works from a mesh, which is faster for big models and draws parallel views only.

## SVG

`bitbybit.occt.io.saveShapeSvg` draws the same view straight into an SVG file and downloads it, with the hidden edges dashed when `drawHidden` is true. `saveShapeSvgAndReturn` returns the SVG text as well, to show on a page or send elsewhere. Both take the shape and the frame, not the result of `hiddenLines`. Given the shape's `unit`, the drawing states its true width and height, so it prints and imports at size; left out, it has only a view box.

## DXF

The drawing lies flat on the ground plane, which is what the DXF export needs. Turn each compound into paths with `bitbybit.occt.io.shapeToDxfPaths`, put each on its own layer with `dxfPathsWithLayer` (the visible edges on one layer in black, the hidden ones on another in grey) and write the file with `dxfCreate`. CAD programs then show, hide or restyle each layer. Written as `acadVersion` AC1015 with a `unit`, the file states its unit in its header, so a CAD program opens it at true size. [DXF drawings](./dxf-file-format-for-2d-drawings) walks through the DXF steps on text and patterns.

Sections through a part, which drawings often show beside the views, are on [Sections and slices](../operations/sections-and-slices).
