# Rete shortcuts

Keys that change the canvas work while the focus is not in a field; inside a field they edit the field.

| Windows and Linux | macOS | What it does |
|---|---|---|
| <kbd>Ctrl+Z</kbd> | <kbd>⌘Z</kbd> | Undo the last change on the canvas |
| <kbd>Ctrl+Y</kbd> | <kbd>⌘Y</kbd> | Redo it |
| <kbd>Ctrl</kbd>+click | <kbd>⌘</kbd>+click | Add a node to the selection |
| <kbd>Ctrl</kbd>+drag on empty canvas | <kbd>⌘</kbd>+drag | Select every node the box touches |
| <kbd>Esc</kbd> | <kbd>Esc</kbd> | Clear the selection |
| <kbd>Ctrl+C</kbd> | <kbd>⌘C</kbd> | Copy the whole script, while no node is selected |
| <kbd>Ctrl+V</kbd> | <kbd>⌘V</kbd> | Paste a copied Rete script: at once on an empty canvas, otherwise asking whether to <Ui>Merge</Ui> it with the script or <Ui>Overwrite</Ui> it |
| <kbd>Ctrl+S</kbd> | <kbd>⌘S</kbd> | Save, in a project on bitbybit.dev |
| <kbd>F4</kbd> | <kbd>F4</kbd> | <Ui>Swap Canvas</Ui>: switch between the canvas and the 3D view, when split screen is off |

## In the search

| Key | What it does |
|---|---|
| <kbd>Enter</kbd> | In <Ui>Add components</Ui>, add the first result; in <Ui>Find on canvas</Ui>, go to the next match |
| <kbd>↓</kbd> and <kbd>↑</kbd> | In <Ui>Find on canvas</Ui>, go to the next or the previous match |

## With the mouse

| Gesture | What it does |
|---|---|
| Right-click the canvas | Open the search |
| Drag empty canvas | Pan |
| Wheel | Zoom |
| Double-click empty canvas | Zoom in |
| Double-click a node | Turn the 3D view to the node's geometry |
| Double-click a module definition | Go inside the module |
| Double-click a comment | Edit its text |
