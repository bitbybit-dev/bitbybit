# Build a drone: a module that repeats

The arms, motors, propellers, legs and standoffs all stand evenly around the drone. Instead of building that again for each, you build it once as a [module](../../features/modules.md): a graph of its own that takes a shape and a count and gives back the copies, turned. Every instance of the module runs that graph with its own values.

The copies are made as lists. A [list wired into an input that takes one value](../../features/lists.md) arrives whole rather than once per item, so components that take lists do the repeating: repeat makes the copies, and rotate shapes pairs each copy with its own angle.

Once Around exists, it cuts the plate's four leg openings and places the standoffs that hold the plates apart, each with a bolt from below and one from above.

4. A code component works out the angles, half a step off the axes: 45, 135, 225 and 315 for four. A few lines say this more plainly than a dozen nodes.

   - Add **typescript editor** as *angles*: hidden, in the *Around* group, with the code below.
   - Wire **count** › value into **angles** › inputs.

   ```typescript
   const start = async (inputs: any, index: number) => {
       const count = Math.max(1, Math.round(inputs));
       return Array.from({ length: count }, (_, i) => (i + 0.5) * 360 / count);
   }
   ```

8. A bolt for the standoffs: a code component revolves its profile and cuts the hexagon socket into its head. A number gives its length, 8 millimetres.

   - Add **number** as *bolt length*: number 8.
   - Add **typescript editor** as *M3 bolt*: hidden, with the code below.
   - Wire **bolt length** › result into **M3 bolt** › inputs.
   - Press <Ui>Add a comment</Ui>, double-click the comment and write:

     > ### M3 bolt
     > A socket-head bolt from a code component: a profile revolved into its body, with a hexagon socket cut into the head. The standoffs and the legs use it.

   - Select the comment, *bolt length* and *M3 bolt*, press <Ui>Group selected components</Ui> and title the group *M3 bolt*.

   ```typescript
   const start = async (inputs: any, index: number) => {
       const length = inputs;
       const profile = [[0, -3, 0], [2.35, -3, 0], [2.75, -2.6, 0], [2.75, 0, 0], [1.5, 0, 0], [1.5, length - 0.4, 0], [1.1, length, 0], [0, length, 0]];
       const outline = await bitbybit.occt.shapes.wire.createPolygonWire({ points: profile });
       const face = await bitbybit.occt.shapes.face.createFaceFromWire({ shape: outline, planar: true });
       const body = await bitbybit.occt.operations.revolve({ shape: face, angle: 360, direction: [0, 1, 0], copy: false });
       const hexagon = await bitbybit.occt.shapes.wire.createNGonWire({ nrCorners: 6, radius: 1.45, center: [0, -3.5, 0], direction: [0, 1, 0] });
       const socketFace = await bitbybit.occt.shapes.face.createFaceFromWire({ shape: hexagon, planar: true });
       const socket = await bitbybit.occt.operations.extrude({ shape: socketFace, direction: [0, 2.5, 0] });
       return bitbybit.occt.booleans.difference({ shape: body, shapes: [socket], keepEdges: false });
   }
   ```
