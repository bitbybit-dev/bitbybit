# Build a drone: arms around the frame

Both modules come together on the main graph. One instance of Arm makes an arm from the sliders, and instances of Around repeat each of its parts as many times as the arms slider says. Because Arm has one output per material, every repeated part can go to the draw component of its colour.

Two of the parts need a little more than repeating, and [code components](../../features/code-nodes.md) do it: neighbouring propellers must turn opposite ways, and the lights are green at the front and red at the back.

   - Wire **arms** › result into **propellers around** › count.

   - Wire **propellers around** › copies into **alternate spin** › inputs.
   - Wire **alternate spin** › result into **accent** › entity.
   - Press <Ui>Add a comment</Ui>, double-click the comment and write:

     > ### Spin
     > Neighbouring propellers turn opposite ways, so the drone does not spin. Every second propeller is mirrored across its own arm, and each is turned a little, so the blades do not all line up.

   - Select the comment, *propellers around* and *alternate spin*, press <Ui>Group selected components</Ui> and title the group *Spin*.

   ```typescript
   const start = async (inputs: any, index: number) => {
       const propellers = inputs;
       const count = propellers.length;
       const spun = [];
       for (const [i, propeller] of propellers.entries()) {
           const angle = (i + 0.5) * 360 / count * Math.PI / 180;
           const centre = (await bitbybit.occt.analysis.measure.tightBoundingBox({ shape: propeller })).center;
           const turned = await bitbybit.occt.transforms.rotateAroundCenter({ shape: propeller, angle: i * 37, center: [centre[0], 0, centre[2]], axis: [0, 1, 0] });
           spun.push(i % 2 === 0 ? turned : await bitbybit.occt.transforms.mirrorAlongNormal({ shape: turned, origin: [0, 0, 0], normal: [Math.sin(angle), 0, Math.cos(angle)] }));
       }
       return spun;
   }
   ```

   ```typescript
   const start = async (inputs: any, index: number) => {
       const lights = [];
       for (const light of inputs) {
           const centre = (await bitbybit.occt.analysis.measure.tightBoundingBox({ shape: light })).center;
           if (centre[2] > 0) {
               lights.push(light);
           }
       }
       return lights;
   }
   ```
