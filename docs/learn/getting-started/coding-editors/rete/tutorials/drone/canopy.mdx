# Build a drone: canopy and electronics

The canopy covers the electronics between the plates. It is a loft, a solid stretched through a series of outlines, and a code component makes the outlines because each one differs from the last in five numbers. The honeycomb on its sides is not geometry cut into it: it is a set of wires, drawn on their own over the canopy. The hatch on top carries the bitbybit logo, read from a STEP file that a fetch text component downloads, the way any model from another CAD program can come into a graph.

2. A honeycomb is traced on the canopy's sides: a code component takes the loft, grows it a little, and divides each side face into hexagon wires, eight across the long sides and five across the short ones. A draw of its own shows the wires as white lines, over the canopy's own material.

   - Add **typescript editor** as *honeycomb*: hidden, in the *Canopy* group, with the code below.
   - Wire **canopy loft** › result into **honeycomb** › inputs.
   - Add **translate** as *honeycomb on canopy*: translation [0, 16, 0], hidden, in the *Canopy* group.
   - Wire **honeycomb** › result into **honeycomb on canopy** › shape.
   - Add **options occt shape** as *honeycomb look*: precision 0.05, draw two sided off, edge colour #f2f2f2, edge width 8, in the *Materials* group.
   - Wire **paint material** › result into **honeycomb look** › faceMaterial.
   - Add **draw any async** as *honeycomb* in the *Materials* group.
   - Wire **honeycomb look** › result into **honeycomb** › options.
   - Wire **honeycomb on canopy** › result into **honeycomb** › entity.

   ```typescript
   const start = async (inputs: any, index: number) => {
       const canopy = inputs;
       const centre = (await bitbybit.occt.analysis.measure.tightBoundingBox({ shape: canopy })).center;
       const grown = await bitbybit.occt.transforms.scale3d({ shape: canopy, scale: [1.02, 1.02, 1.02], center: [centre[0], 0, centre[2]] });
       const faces = await bitbybit.occt.shapes.face.getFaces({ shape: grown });
       const areas = await bitbybit.occt.shapes.face.getFacesAreas({ shapes: faces });
       const largestSide = Math.max(...areas.slice(0, -2));
       const wires = [];
       for (const [i, face] of faces.entries()) {
           const normal = await bitbybit.occt.shapes.face.normalOnUV({ shape: face, paramU: 0.5, paramV: 0.5 });
           if (Math.abs(normal[1]) > 0.9) {
               continue;
           }
           const across = areas[i] > largestSide * 0.7 ? 8 : 5;
           wires.push(...await bitbybit.occt.shapes.face.subdivideToHexagonWires({ shape: face, nrHexagonsU: across, nrHexagonsV: 3, flatU: false, scalePatternU: [0.8], scalePatternV: [0.8], filletPattern: [0.35], offsetFromBorderU: 0.05, offsetFromBorderV: 0.08 }));
       }
       return bitbybit.occt.shapes.compound.makeCompound({ shapes: wires });
   }
   ```

       const rod = await bitbybit.occt.shapes.solid.createCylinder({ radius: 1.5, height: 42, center: [0, 0, 0], direction: [0, 1, 0] });
       const tip = await bitbybit.occt.shapes.solid.createSphere({ radius: 1.5, center: [0, 42, 0] });
       const antenna = await bitbybit.occt.booleans.union({ shapes: [rod, tip], keepEdges: false });
       const tilted = await bitbybit.occt.transforms.rotate({ shape: antenna, axis: [1, 0, 0], angle: 225 });
       const pair = [];
       for (const x of [-14, 14]) {
           pair.push(await bitbybit.occt.transforms.translate({ shape: tilted, translation: [x, 0, -67] }));
       }
       return bitbybit.occt.shapes.compound.makeCompound({ shapes: pair });
   }
