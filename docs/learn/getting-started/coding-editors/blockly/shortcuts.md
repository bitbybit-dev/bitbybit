# Blockly shortcuts

Keys that change the workspace work while a block or the workspace has the focus; inside a field they edit the field.

| Windows and Linux | macOS | What it does |
|---|---|---|
| <kbd>Ctrl+C</kbd> | <kbd>⌘C</kbd> | Copy the selected block, with the blocks plugged into it |
| <kbd>Ctrl+V</kbd> | <kbd>⌘V</kbd> | Paste the copied block |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | <kbd>Delete</kbd> | Delete the selected block |
| <kbd>Ctrl+Z</kbd> | <kbd>⌘Z</kbd> | Undo |
| <kbd>Ctrl+Shift+Z</kbd> | <kbd>⌘⇧Z</kbd> | Redo |
| <kbd>Ctrl+S</kbd> | <kbd>⌘S</kbd> | Save, in a project on bitbybit.dev |
| <kbd>F4</kbd> | <kbd>F4</kbd> | <Ui>Swap Canvas</Ui>: switch between the workspace and the 3D view, when split screen is off |

## With the mouse

| Gesture | What it does |
|---|---|
| Drag a block | Move it, with everything plugged into it and stacked under it |
| Drop a block on the trash can | Delete it |
| Drag empty workspace | Move around the workspace |
| Wheel | Zoom |
| Right-click a block | Open [its menu](./features/blocks.md) |
| Right-click empty workspace | Undo, redo, clean up, collapse or expand every block |
