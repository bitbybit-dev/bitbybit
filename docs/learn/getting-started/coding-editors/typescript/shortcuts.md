# TypeScript editor shortcuts

The editor is Monaco, so most keys of VS Code work in it. These are the ones worth knowing first.

| Windows and Linux | macOS | What it does |
|---|---|---|
| <kbd>Ctrl+Space</kbd> | <kbd>⌃Space</kbd> | Open the suggestions where the cursor is |
| <kbd>F12</kbd> | <kbd>F12</kbd> | Go to where the name under the cursor is defined |
| <kbd>F2</kbd> | <kbd>F2</kbd> | Rename the name under the cursor everywhere it is used |
| <kbd>Ctrl+/</kbd> | <kbd>⌘/</kbd> | Turn the line, or the selected lines, into a comment and back |
| <kbd>Shift+Alt+F</kbd> | <kbd>⇧⌥F</kbd> | Format the file |
| <kbd>F1</kbd> | <kbd>F1</kbd> | Open the command palette, where every command of the editor can be found by name |
| <kbd>F4</kbd> | <kbd>F4</kbd> | <Ui>Swap Canvas</Ui>: switch between the code and the 3D view, when split screen is off |
| <kbd>Ctrl+S</kbd> | <kbd>⌘S</kbd> | Save, in a project on bitbybit.dev |

Undo, redo, copy, paste, find and select work as in any editor, with <kbd>Ctrl</kbd> on Windows and Linux and <kbd>⌘</kbd> on macOS.
