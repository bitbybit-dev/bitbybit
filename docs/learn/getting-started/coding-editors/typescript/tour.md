# A tour of the TypeScript editor

{/* shot: typescript.start.tour/window */}

The numbers match the picture, which shows the script [Hello World](./tutorials/hello-world.mdx) writes.

1. **<Ui>Files</Ui>.** The files and folders of the script, with <Ui>New file</Ui> and <Ui>New folder</Ui>. The file with the play icon, `main.ts`, is where the run starts. A file with a mistake shows how many it has. [Files and imports](./features/files-and-imports.md) explains the rest.
2. **The tabs.** The files you opened; click one to edit it.
3. **The code.** Suggestions appear as you type, a hover explains what is under the pointer, and a mistake is underlined before you run. [IntelliSense and errors](./features/intellisense-and-errors.md) explains each.
4. **The 3D view.** What the script draws. Turn it with the left mouse button, pan with the right, zoom with the wheel.
5. **The console.** What the script logs, and the errors of a run.
6. **<Ui>Run The Code</Ui>.** Runs the script from `main.ts`.
7. **<Ui>More</Ui>.** Import, export, copy and paste the script, <Ui>Export to runner</Ui>, settings, and links to the documentation.

[Running code](../../basics/running-code.md) explains the split between the code and the 3D view.
