# A Parametric Cube

Parametric means that a shape follows its parameters: change a number and the geometry is rebuilt from it. In code a parameter is simply a value the rest of the script reads. Here one constant sizes a cube made by OCCT, the CAD kernel behind solids on Bitbybit.

## Before you start

Open [an empty TypeScript editor](https://bitbybit.dev/app?editor=typescript). If this is your first TypeScript script, [Hello World](./hello-world.mdx) shows the basics first.

## The steps

{/* steps:start - generated from the tutorial's steps, which the capture plays in the editor; edits between these markers are overwritten */}

1. **Add this line to `main.ts`:**

   ```typescript
   const size = 3;
   ```

   One constant holds the parameter; everything that depends on it reads it.

   {/* shot: typescript.tutorials.parametric-cube/size */}

2. **Type `bitbybit.occt.shapes.solid.`** and IntelliSense lists what the API offers there. **Then add these lines to `main.ts`:**

   ```typescript
   const cubeOptions = new Bit.Inputs.OCCT.CubeDto();
   cubeOptions.size = size;
   const cube = await bitbybit.occt.shapes.solid.createCube(cubeOptions);
   ```

   The API follows its categories: occt, then shapes, then solid. The cube is a solid made by OCCT, the CAD kernel, so it is awaited.

   {/* shot: typescript.tutorials.parametric-cube/cube */}

3. **Add this line to `main.ts`:**

   ```typescript
   await bitbybit.draw.drawAnyAsync({ entity: cube });
   ```

4. **Run the script.** Press <Ui>Run The Code</Ui>, the play button at the lower left.

   {/* shot: typescript.tutorials.parametric-cube/run */}

5. **Change `const size = 3;` to `const size = 5;`.**

   Change the one number, run again, and the cube follows.

6. **Run the script.** Press <Ui>Run The Code</Ui>, the play button at the lower left.

   {/* shot: typescript.tutorials.parametric-cube/bigger */}

## What you learned

- **One value can drive a model.** Every line that reads `size` follows it.
- **The API follows its categories,** `bitbybit.occt.shapes.solid.createCube` sitting where the cube does in [Rete](../../rete/intro.md) and [Blockly](../../blockly/intro.md).
- **Split a growing script into files** with [files and imports](../features/files-and-imports.md).
