# Creating a New Project

{/* shot: platform.projects.create/form */}

1. Open <Ui>My Projects</Ui> in the bitbybit.dev header. While an editor is open, the button with the script's title beside it opens the same list.
2. Choose <Ui>New project</Ui>.
3. Under <Ui>Keep it in</Ui>, choose where the project lives:
   - <Ui>Cloud</Ui> keeps it in your account, to open on any device and to share. It needs you to be signed in, and a free place in your plan's [cloud projects](/learn/getting-started/basics/projects/intro#how-many-projects-your-plan-keeps).
   - <Ui>This browser</Ui> keeps it on this device only.
4. Give it a <Ui>Title</Ui>. A cloud project also takes a <Ui>Description</Ui>.
5. For a cloud project, name its <Ui>First script</Ui> and choose its editor: Rete, Blockly, TypeScript or the Designer, which is part of the Gold plan.
6. Choose <Ui>Create project</Ui>.

A cloud project opens its first script in the editor you chose, which starts with a small example to change or delete. A project in this browser is selected in the list, empty: add its scripts with <Ui>New script</Ui>, as [Creating Scripts](/learn/getting-started/basics/scripts/create-script) shows.

Every project, whichever way you made it, is listed in [My Projects](https://bitbybit.dev/projects/my).
