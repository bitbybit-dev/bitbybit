# Finding Your Scripts

Every script is in a project, so you find a script by its project.

<Shot id="platform.scripts.find/projects-dialog" />

1. Open [My Projects](https://bitbybit.dev/projects/my). While an editor is open, the button with the script's title, at the left of the bitbybit.dev header, opens the same list over the editor.
2. On the left, choose the project. The list has:
   - <Ui>Cloud</Ui>: your projects in your account;
   - <Ui>This browser</Ui>: projects kept on this device, <Ui>Drafts</Ui> among them;
   - <Ui>Viewing</Ui>: other people's projects you have open;
   - <Ui>Community</Ui>: <Ui>Browse community projects</Ui>.
3. The project's scripts are listed under it, each with its editor and when it was last edited. Choose <Ui>Open</Ui> beside one.

<Ui>Search projects</Ui>, above the list, finds a project by its title. To find other people's work, [search the public scripts](/learn/getting-started/basics/scripts/search-public).
