# Basics

Whichever editor you choose, the same few things hold on bitbybit.dev. This section covers them once, so the pages about [Rete, Blockly and TypeScript](/learn/getting-started/coding-editors) and about [the Designer](../designer.md) can stay with what is their own.

- **[Projects](./projects/intro.md)** hold your work, in the cloud or in this browser, each with a cover, a description and a visibility.
- **[Scripts](./scripts/intro.mdx)** are what you open in an editor: a Rete graph, Blockly blocks, TypeScript code or a Designer project. They save themselves as you work, keep a history, export to files, and can be shared as a link, a preview or an embed.
- **[Assets](./assets/intro.mdx)** are files a script reads, such as a STEP model, a glTF file or a texture, kept with the project or in this browser.
- **[Running code](./running-code.md)** explains when a script runs, where its result and its console appear, and how to tell it is still working.
- **[Drawing](./drawing.mdx)** explains why a shape only appears once it is drawn, and what a drawn object can do.
- **[Errors](./errors.md)** shows where each editor tells you what went wrong, and how to find the cause.
