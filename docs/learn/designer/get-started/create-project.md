# Create a Designer project

A project holds scripts, and a Designer script holds a whole design: every part and assembly document in it. You can keep a project in the cloud, where you reach it from any device, or in this browser only.

<Shot id="designer.get-started.create-project/form" />

## A new project with a Designer script

1. Open <Ui>My Projects</Ui> in the bitbybit.dev header.
2. Choose <Ui>New project</Ui>.
3. Under <Ui>Keep it in</Ui>, choose <Ui>Cloud</Ui> or <Ui>This browser</Ui>. The cloud needs you to be signed in.
4. Give it a <Ui>Title</Ui>, and for a cloud project a description if you like.
5. For a cloud project, name its first script and choose <Ui>Designer</Ui> as its editor.
6. Choose <Ui>Create project</Ui>.

A cloud project opens its first script in the Designer straight away, with no documents yet: start with a new part. A project in this browser starts empty: add a script to it as below.

## A Designer script in a project you have

1. In <Ui>My Projects</Ui>, choose the project.
2. Choose <Ui>New script</Ui>.
3. Name it, choose <Ui>Designer</Ui> as its editor, and choose <Ui>Create and open</Ui>.
